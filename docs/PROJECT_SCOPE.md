# Project Scope

Goal: Build the first working slice of this project.

## First working slice

1. Load local configuration safely.
2. Read a small list of user-provided feeds or sources.
3. Report what would be watched before adding any automated download behavior.
4. Add tests around configuration and parsing before expanding the workflow.

## Boundaries

- Do not commit private credentials or personal config.
- Keep network/download behavior explicit and testable.
- Use this only with feeds, files, and content you have permission to access.
